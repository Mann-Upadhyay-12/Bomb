# Captcha model compression study

"trusted @98%" = share of captchas whose confidence clears the threshold at which trusted answers are ≥98 % right.
Δ vs today = paired McNemar test against the shipped format (teacher, fp16): captchas only this one gets right / only today's gets right, p-value.
